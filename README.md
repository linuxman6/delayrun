# アプリ連続起動ツール Pro (App Delay Runner Pro)

Windowsの起動時や作業開始時に、複数のアプリ、フォルダ、Webサイト（URL）を指定した秒数のディレイ（待機時間）を挟みながら順番に自動起動・一括展開できる、AutoHotkey v2製の軽量・多機能ツールです。

眩しさを抑えた**スタイリッシュなダークモードGUI**を標準搭載しています。


---

## ✨ 主な機能

- **⏳ ディレイ（待機秒数）付きの連続実行**
  - アプリごとに個別の待機時間を設定可能。PC起動直後の負荷を分散しながらスマートに環境を立ち上げられます。
- **📁 フォルダ ＆ 🌐 URL（Webサイト）にも対応**
  - ソフトウェア（`.exe`, `.lnk`）だけでなく、よく使う作業フォルダや、ブラウザで開きたいWebサイトも一括で登録・起動できます。
- **🎯 直感的なドラッグ＆ドロップ追加**
  - ファイルやフォルダをウィンドウ内にポイッと落とすだけで、一発でリストに追加できます。
- **⏸️ いつでも止められる「中断ボタン」搭載**
  - カウントダウン中や連続実行の途中でも、ボタン一つで安全に処理を停止・キャンセルできます。
- **⚡ 管理者権限（UAC）の個別設定**
  - 特定のアプリだけを「管理者として実行」するよう、チェックボックスで簡単に指定可能です。
- **🔼 柔軟な並び替え＆テスト実行**
  - 起動する順番の入れ替え（上へ/下へ）や、選択したアイテムが正しく動くかその場で確認できる単発テスト機能を搭載。
- **⚠️ 柔軟なエラーハンドリング**
  - 起動に失敗した際、「処理をその場で停止」するか「無視して次に進む（スキップ）」かをワンクリックで切り替えられます。
- **🤖 コマンドライン引数（自動実行）に対応**
  - `/run` オプションを付けて本ツールを起動すると、GUIを開いたのち自動的に連続実行を開始し、完了後に自動で終了します。Windowsのスタートアップ登録に最適です。

## 🚀 使い方・導入方法

### 1. 動作環境
- **Windows 10 / 11**
- **AutoHotkey v2.0 以上** がインストールされていること

### 2. 起動方法
1. 前半（GUI構築）と後半（関数群）を統合した `.ahk` ファイル（例：`DelayRun.ahk`）を作成します。
2. ファイルをダブルクリックして実行します。
3. 初回起動時、スクリプトと同じフォルダに設定保存用の `delayrun.ini` が自動生成されます。

### 3. Windowsスタートアップへの登録方法
PC起動時にバックグラウンド（または自動）で一括起動させたい場合は、Windowsのショートカットを作成し、**リンク先の末尾に `/run` を追加**して `shell:startup` フォルダに配置してください。

**設定例（ショートカットのリンク先）:**
```text
"C:\Path\To\DelayRun.ahk" /run
```

## 🛠️ 開発者向け（仕様）

- **設定の永続化**: すべての設定（起動パス、秒数、管理者フラグ、エラーモード）は、同一ディレクトリ内の `delayrun.ini` にリアルタイムで同期保存されます。
- **非同期カウントダウン**: `SetTimer` を利用した非同期制御を行っているため、カウントダウン中もGUIがフリーズせず、ウィンドウサイズの変更や中断操作を受け付けます。
- **UXTheme APIの利用**: Windowsの内部API（`uxtheme.dll`）を呼び出し、通常は白くなってしまうListViewのヘッダーや枠線まで一貫したダークモードスタイルを適用しています。
